# EvaHPX 0.0.4

EvaHPX shows the parcels of an HPX program and the MPI messages below them on one timeline. Version 0.0.4 is the first release under the new name; the viewer and the measuring chain work as in 0.0.3.

## What is new

* **New name: EvaHPX** (Exploration, Visualization & Analysis HPX), formerly EduHPX, with a new logo. The repository is now <https://github.com/FuldaHPC/tool-evahpx> (the old address forwards to it).
* The downloads, the app, the commands and the measuring MPI carry the new name: `EvaHPX_<version>*`, `evahpx-run`, `evahpx-merge`, `evahpx_mpi_data-5.0.11rc1-evahpx1.tar.gz`. Run files of earlier versions (`# eduhpx_run_csv 1`) still open.
* The install scripts try a download again when the server answers with an error.

## Files

- Linux: `EvaHPX_0.0.4-x86_64.AppImage` (make it executable, then start it)
- macOS: `EvaHPX_0.0.4.dmg` (if macOS blocks the app: see the README of the repository, section macOS)
- Windows: `EvaHPX_0.0.4-windows.zip` (unpack, start `evahpx.exe`)
- `EvaHPX_0.0.4_examples.zip`: the example run files (they are also built into the app: File > Examples)
- `evahpx_mpi_data-5.0.11rc1-evahpx1.tar.gz` and `evahpx_mpi_data-5.0.11rc1-evahpx1.tar.gz.sha256`: the measuring MPI (source), to trace your own program: see the [tracing guide](https://github.com/FuldaHPC/tool-evahpx/blob/main/docs/tracing_guide.md)
